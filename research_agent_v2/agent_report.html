下一步：模型池扩展

暂缓：GPU 优先

  • DIN / DIEN：序列兴趣与注意力。
  • SASRec / BERT4Rec：序列 Transformer。
  • DCNv2、xDeepFM 与更大 DeepFM。
  • MMoE / ESMM 多任务共享底座。

这些模型需要更高的序列训练和显存成本；当前先以 CPU MVP 跑通端到端闭环，暂未纳入，并非判定无价值。

CPU 可继续

  • DeepFM / DCN 多 seed 稳定性验证。
  • 互补性驱动的两模型融合。
  • 轻量历史、时间上下文、pairwise/listwise 损失。
  • random exposure log 无偏审计。

扩展原则

不盲目堆模型。Data Agent 先给可验证证据，Planner 转为受控 recipe，Evaluator 只按官方 primary 保留候选。GPU 可用后，新模型会进入同一搜索池和融合池。

合规边界：训练、研究和选模仅用 train + validation；test 仅在最终导出时读取曝光特征，不读取 long_view、click、like、comment、play_time 等后验列。
裁决规则：Qwen 提供研究建议，但不能覆盖官方 GAUC / nDCG@5 / primary 的 validation 结果。
